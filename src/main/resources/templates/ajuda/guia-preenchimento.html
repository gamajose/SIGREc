Guia de preenchimento

Orientações para preenchimento correto das solicitações TFD/APAC.

Dados obrigatórios

  • Paciente devidamente identificado.
  • CPF, CNS e data de nascimento atualizados.
  • Procedimento SIGTAP corretamente selecionado.
  • Justificativa clínica preenchida.
  • Anexos enviados quando necessários.

Recomendações

Revise os dados antes do envio, utilize informações objetivas e mantenha os documentos anexados legíveis para facilitar o processo de análise da regulação.
