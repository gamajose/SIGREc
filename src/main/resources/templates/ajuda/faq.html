Ajuda

Perguntas frequentes

Respostas rápidas para dúvidas comuns sobre o SIGREc.

Como abrir uma solicitação?

Acesse o menu Solicitações, selecione “Nova solicitação”, preencha os dados necessários e envie para análise.

Como consultar procedimentos SIGTAP?

Utilize o menu Procedimentos ou a opção “Consulta rápida SIGTAP” disponível em Ferramentas.

Como solicitar suporte?

Utilize a Central de Suporte disponível no sistema para registrar dúvidas, erros ou solicitações internas.
